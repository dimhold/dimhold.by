# Гульні — the games section

Web adaptations of Belarusian folk games, for dimhold.by.

This folder is the section's workshop: research, sourcing and design decisions
live here. Shipping code will live under `src/` like everything else; this stays
as the record of *why* a game was chosen, what it actually is, and where the
claims come from.

| File | What it holds |
| --- | --- |
| `RESEARCH.md` | The ethnographic groundwork: which games exist, how Belarusian each one really is, what the sources say, and what turned out not to exist at all. |
| `ADAPTATION.md` | Which of them survive contact with a browser, and the mechanics proposed for each. |

## The rule this section is held to

Every game shipped here must be traceable to a named source. Where a claim of
Belarusian uniqueness is made on the site, the literature has to actually make
that claim — not merely fail to contradict it. Where the tradition is shared
with the neighbours, the site says so; the interesting part was never
exclusivity, it is the particular text, tune and implement.
